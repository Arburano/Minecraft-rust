# mods/

Моди, що постачаються разом із рушієм. Формат описано в `docs/modding/`.

- `core/` — базовий геймплей (блоки, предмети, моби, крафт, генерація). Пишеться лише через публічний API (`wit/engine-api.wit` + датапаки). Якщо чогось бракує в API — спершу ADR і розширення API, а не обхід.

Сторонні та експериментальні моди тут не зберігаються: вони живуть в окремих репозиторіях і ставляться через реєстр модів.
