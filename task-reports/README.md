# Task reports

One report per completed task, as required by [`AGENTS.md`](../AGENTS.md) ("Task reports").

- File name: `<task-id>-<slug>.md`, e.g. `t0-03-world-palette-section.md`.
- Written in English. Committed together with the task's changes.

## Template

```markdown
# T0-03: world palette section

## What was done

Summary of the implementation, files/crates touched, tests and benchmarks run
(with honest numbers: machine, number of runs, VM flag if applicable).

## What went wrong

Mistakes, failed approaches, reverted changes, and how they were resolved.
Write "None" if there were none.

## Issues encountered

Blockers, deviations from specifications or ADRs, open questions raised,
and anything left unfinished or needing follow-up.
```
