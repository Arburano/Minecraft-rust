# 0011. Light on the client, LOD from the server

Status: Accepted (2026-11-15)

## Context

Light — up to 4 KB per section; sending it over the network is expensive. LOD generated by the client requires the world seed, and a seed gives a cheat for finding ore.

## Decision

The client computes light for rendering with the same code as the server (the server computes it only for gameplay, lazily). The server computes LOD and sends LOD sections in the palette format; the client caches them on disk and does not have the seed.

## Consequences

- Less traffic; light determinism between client and server is covered by a hash test.
- The server keeps the LOD pyramid (+≈ 14% volume).
- Until LOD arrives — fog.

## Alternatives considered

- Light from the server — traffic.
- LOD on the client with a seed — cheats.
