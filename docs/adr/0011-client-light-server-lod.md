# 0011. Світло на клієнті, LOD із сервера

Статус: Прийнято (2026-11-15)

## Контекст

Світло — до 4 КБ на секцію; слати його мережею дорого. LOD, згенерований клієнтом, вимагає seed світу, а seed дає чит на пошук руд.

## Рішення

Клієнт рахує світло для рендера тим самим кодом, що й сервер (сервер — лише для геймплея, ліниво). LOD рахує сервер і шле LOD-секції в палітровому форматі; клієнт кешує їх на диску і не має seed.

## Наслідки

- Менше трафіку; детермінізм світла клієнт/сервер покривається тестом хешу.
- Сервер тримає LOD-піраміду (+≈ 14% обсягу).
- Поки LOD не прийшов — туман.

## Розглянуті альтернативи

- Світло з сервера — трафік.
- LOD на клієнті з seed — чити.
