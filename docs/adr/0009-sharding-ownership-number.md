# 0009. Шарди з номером власності

Статус: Прийнято (2026-11-15)

## Контекст

5 000+ гравців потребують кількох нод. Передача сутності між нодами не має дюпати чи губити предмети. Core NATS доставляє «не більше одного разу»; класичний 2PC зависає при падінні координатора.

## Рішення

Просторові клітини належать нодам; клієнт підключений до шлюзу. Кожна сутність має номер власності, що росте при передачі; прийом ідемпотентний, команди зі старим номером відкидаються; доставка «щонайменше один раз» (JetStream або прямий канал з підтвердженням). Тіньові копії в зоні перекриття — лише для показу; дії через кордон — команда власнику.

## Наслідки

- Без дюпів при повторах і падіннях (перевірка 10 000 автотестами).
- Дії через кордон мають затримку мережі між нодами.
- Джерело правди власника — відкрите питання №3.

## Розглянуті альтернативи

- 2PC — див. контекст.
- MultiPaper-подібний майстер чанків — бета, не описує переміщення сутностей.
