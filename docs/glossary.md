# Глосарій

| Термін | Значення |
| --- | --- |
| Секція | Куб 16³ блоків, одиниця зберігання, світла і мережевої передачі. |
| Колона | Стовп секцій на всю висоту світу (24 секції при висоті 384). Те, що в Minecraft зветься «чанком». |
| Чанк (у метриках дальності) | Горизонтальна клітина 16×16 блоків. «12 чанків прорисовки» = радіус 12 колон. |
| Меш-чанк | Куб 32³ блоків (2×2×2 секції), одиниця мешингу. ADR-0005. |
| Рендер-пакет | 2×2×2 меш-чанки (64³ блоків), малюється однією командою. ADR-0005. |
| Квад | Прямокутна грань після жадібного мешингу, упакована в `u64` (8 байт). |
| Маски | Бітові маски непрозорих і прозорих вокселів меш-чанка; вхід для `fast_mesh`. |
| Gather | Розпакування секцій у плаский буфер 34³ (з паддінгом) перед мешингом. |
| Регіон (потоковий) | Динамічна група секцій навколо гравців, яку тікає один потік. ADR-0008. Не плутати з ігровою зоною. |
| Ігрова зона | Статична розмітка мапи (біом, складність, свої таблиці спавну). PRD §14, № 11. |
| Глобальний регіон | Окремий регіон для стану світу (час, погода, таблиці); інші читають його знімок попереднього тіку. |
| Буфер регіону | Порожні секції навколо зайнятих; два регіони ніколи не межують впритул. |
| Фази тіку | `PreTick → Simulate → Exchange → PostTick`. |
| Нода | Один процес сервера на одній машині. |
| Шард / клітина | Частина світу (напр. 512×512 блоків), якою володіє одна нода. |
| Шлюз | Процес, що тримає QUIC-з'єднання клієнта і маршрутизує його до ноди-власника. |
| Номер власності | Лічильник, що росте при кожній передачі сутності між нодами; захищає від дюпів. ADR-0009. |
| LOD n | Секція 16³ вокселів, де воксель = 2ⁿ блоків. |
| Датапак | Мод рівня 1: TOML/JSON + асети, без коду. |
| WASM-мод | Мод рівня 2: компонент WebAssembly за контрактом `wit/engine-api.wit`. |
| Нативний плагін | Мод рівня 3: Rust-крейт, що збирається з рушієм. Лише команда проєкту. |
| Epoch | Механізм wasmtime для переривання гостя за часом; сторож від зависання, 0–9% ціни. |
| Fuel | Детермінований лічильник інструкцій wasmtime; +50–90% ціни, лише для тестів і реплеїв. |
| Хук | Виклик гостя хостом (`on-events`, `run-system`). Завжди пакетний. |
| Профіль якості | Low / Medium / High / Ultra; визначає дальність, тіні, ефекти. |
| Меню-лаунчер | Головне меню гри, що виконує роль лаунчера. ADR-0010. |
| Апдейтер | Окремий крихітний бінарник, що оновлює гру і запускає її. ADR-0010. |
| ADR | Architecture Decision Record, файл у `docs/adr/`. |
